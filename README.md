# DataxAgents website

Placeholder page for **https://dataxagents.github.io**, reserved for a workshop proposal to SIGMOD 2027.

- `main`: a single static page in `site/index.html`.
- `fullsite`: the full Astro website, to be merged back once the proposal is accepted.

Every push to `main` publishes `site/` automatically. You can also start a deploy by hand from the repo's **Actions** tab (**Deploy to GitHub Pages** → **Run workflow**).
